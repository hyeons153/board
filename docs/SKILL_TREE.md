# LONGBOARD LIFE — 기술 트리 기획서

- 버전: v1.6 (2026-11-20)
- 상태: 구현 반영
- 기준: `src/game/data.ts`의 기술 32개(댄싱 18, 트릭 14) 및 사용자 제공 Mini Longboard 기술 분류·참고 점수
- 목적: 기술 ID·선행 조건·숙련도 임계값을 명시해 향후 게임 밸런스와 UI를 일관되게 유지

## 1. 핵심 규칙

1. **기술 습득**: 학습도(`study`) 100%일 때 경기 라인에 사용할 수 있다.
2. **기술 마스터**: 이미 습득한 기술의 숙련도(`mastery`) 100%.
3. **미습득 상위 기술의 최초 해금**: 표에 기록된 **모든 선행 기술의 숙련도 100%**를 충족해야 새로운 기술의 일반 셀프훈련을 시작할 수 있다.
4. **이미 습득한 기술은 상시 셀프훈련 가능**: 해당 기술의 학습도가 이미 100%라면 선행 조건이 미달성이더라도 그 기술을 직접 선택해 숙련도 연마를 계속할 수 있다. NPC 전수로 먼저 습득했거나 기존 저장 데이터에서 이미 보유한 기술에도 동일하게 적용한다. 다른 미습득 상위 기술의 선행 조건까지 충족된 것으로 간주하지는 않는다.
5. **시작 기술**: 새 커리어의 기본 습득 기술은 시작부터 이용 가능하다. 변경 전 저장 기록에서 이미 습득한 기술은 잠그거나 삭제하지 않는다.
6. **기술 구성**: 기존 기술 ID 31개(피투피와 알리 포함)를 유지하고 댄싱 트릭 `ghostride-kickflip`을 추가한다.
7. **피루엣**: 기존 `pirouette`의 표시명은 '피루엣'이다. 기본 동작은 360도 회전이다.
8. **시작 기술**: 댄싱 피터팬·180·크로스스텝, 트릭 180 피봇·노컴플라이를 습득한 상태로 시작한다. 알리와 팝샤빗은 처음부터 학습할 수 있다.
9. **선행 기술이 미달성된 미습득 기술**은 잠금 상태로 표시하고 남은 숙련도를 보여 준다. 이미 습득한 기술은 선행 조건과 관계없이 연마 가능하며, NPC 직접 전수 예외도 유지한다.
10. 학습도 증가량은 난도별로 기본 증가량을 1.00·1.34·1.68·2.02로 나눠 적용한다. 일반·특별훈련과 레슨의 숙련도 증가량에는 초급 1.25배, 중급 1배, 고급 0.8배, 최고급 0.65배를 적용한다.
11. 연습과 대회에서의 기술 성공률은 별개다. 기본 연습 성공률은 체력 중심, 경기 기술 성공률은 숙련도·밸런스·난이도·위험도 및 장비 중심으로 유지한다.

## 3. 트릭 기술 트리 — 노즈 / 테일 (14개)

### 근거 및 설계 원칙

- 실제 **롱보드 댄싱·프리스타일** 튜토리얼, 커뮤니티를 우선 참고한다. 일반 스트리트 스케이트보드의 올리 중심 입문 순서를 그대로 강제하지 않는다.
- [Longboards USA — Freestyle Longboarding](https://longboardsusa.com/pages/the-4-easier-tricks-for-freestyle-longboarding): **피봇 → 샤빗**이 같은 축 회전 동작을 확장하는 기초 계열이라는 점을 참고한다.
- [OUTSIDE Skateshop — Longboard Freestyle Tricks](https://www.outside-shop.com/en/content/59-freestyle-longboard-tricks): 샤빗은 다른 기술과 결합하기 쉬운 기본 회전이며, 베리얼 킥플립 등은 복합 기술임을 참고한다.
- [Odyssey Collective — Fakie No-Comply Bigspin](https://odysseyboards.com/en-au/blogs/longboard-tutorials/fakie-no-comply-bigspin): 노컴플라이 빅스핀이 피봇·노컴플라이 회전 요소를 결합한다는 점을 참고한다.
- [Jeff Corsi — Longboard Bigspin tutorial](https://www.youtube.com/watch?v=Jz1ad_u0vbk): 롱보드용 빅스핀 교육 영상. 스케이트보드용 가이드와 혼동하지 않는다.
- [Reddit r/longboarding, 롱보드 연습 경험](https://www.reddit.com/r/longboarding/comments/yugq1g): 사용자 숙련 순서는 다양하므로 **현실에서 필수인 선행 기술**과 **게임 속 성장 경로**는 구분한다.
- **참고 점수**는 사용자가 제공한 Mini Longboard의 값이다. LONGBOARD LIFE 내부 `points`(6~15점 수준)와 스케일이 다르다. 점수를 그대로 채점 공식에 대입하지 않는다.
- **핵심 간소화**: 노즈는 `피봇 → 샤빗 → 빅스핀 → 비거스핀`의 한 줄을 중심으로 한다. 노컴 빅스핀은 별도 분기이며 빅스핀의 필수 선행 기술이 아니다.
- 모든 상위 기술에 두 가지 선행 조건을 강요하지 않는다. **복합 기술 중 두 가지 기반을 요구하는 노컴 빅스핀·트래플립만 AND 조건**으로 유지한다. 그 외 복합 동작의 추가 권장 기술은 잠금 조건이 아니라 설명/팁으로 안내한다.

### 3-1. 노즈트릭 · 회전 계열 (5개)

| 기술 ID | 표시명 | 참고 점수 | 내부 기본점수(현재) | **개편 선행 조건** | 변경 포인트 |
|---|---|---:|---:|---|---|
| pivot | 180 피봇 | 200 | 6 | 없음 | 시작 습득 유지 |
| shuvit | 샤빗(셔빗) | 250 | 7 | pivot | 유지 |
| no-com-big | 노컴 빅스핀 | 300 | 11 | **no-comply + shuvit** | 별도 분기 유지, 빅스핀으로 연결하지 않음 |
| bigspin | 빅스핀 | 380 | 11 | **shuvit** | 기존 no-com-big 필수 조건 제거 |
| bigger | 비거스핀 | 520 | 14 | bigspin | 유지 |

**주 경로:** `180 피봇 → 샤빗 → 빅스핀 → 비거스핀`

**별도 분기:** `노컴플라이 + 샤빗 → 노컴 빅스핀`

현실에서는 노컴플라이 빅스핀을 다른 방식으로 먼저 익히기도 한다. 이 순서는 게임용 진행 체계다. `no-com-big`은 사용자가 제공한 분류에 따라 노즈트릭으로 표기하되 동작상의 팝/발 디딤 설명은 유지한다.

**진행 경로:**

- `팝샤빗 → 프론팝`
- `알리 → 킥플립 → 베리얼 킥플립`
- `알리 → 힐플립 → 하드플립`
- `킥플립 + 빅스핀 → 트래플립`
- `노컴플라이`는 시작 기술이며, 노즈의 `노컴 빅스핀`을 위한 선행 기술로 사용

`베리얼 킥플립`과 `하드플립`은 복합 기술이라는 설명을 유지한다. 추가 기초기술을 **연습하면 좋다**는 권장 표시는 가능하지만 둘 다 잠금 조건으로 강제하지 않는다.

### 3-3. 난이도 및 점수 밸런스

- 기술별 참고 점수 `200·250·300·350·380·450·520`은 상대적인 난도 순서를 판단하는 자료이지 자동 환산 공식이 아니다.
- 빅스핀은 **난도 3(고급)**, 비거스핀은 **난도 4(최고급)**를 적용한다. 동일 시드 12개로 비교한 결과 일반 대회에 출전한 트릭 집중 육성에서 두 기술을 모두 습득한 비율은 두 설정 모두 12/12였고, 평균 트릭 점수는 기존 난도 94.8점, 상향 난도 94.6점이었다.
- 빅스핀 11점과 노컴 빅스핀 11점처럼 같은 내부 기본점수는 **게임 내 난이도·성공률·전제 경로**와 함께 평가한다. 참고 점수에 비례하여 기존 기본점수를 일괄 변경하지 않는다.
- 테일의 킥플립/힐플립은 현실에서 반드시 하나를 먼저 마스터해야 하는 단선형 기술은 아니다. 게임에서 알리 이후 병렬 분기로 둔다.
- 현재 코드에 알리가 다시 추가되어 있으므로, **이 문서는 기존 알리를 자동 삭제하지 않는다.** 과거 알리 제외 요청과 최신 구현 간 차이가 있으므로 관련 정책 변경은 별도 명시적인 작업으로 다룬다.

### 3-4. 참고 사이트의 비해당 기술 처리

- 참고 사이트의 `돌 넘기`는 특정 기술 도중 장애물을 통과하는 보너스 조건이며, 독립적인 트릭 기술로 추가하지 않는다.
- `노컴 비거스핀`은 신규 추가하지 않는다.
- `트래플립`의 Mini Longboard 기준 점수는 제공되지 않았으므로 미제공으로 표시한다.

### 3-5. 댄싱 참고 점수·고스트라이드 킥플립

| 게임 기술 ID | 표시명 | Mini Longboard 참고 점수 | 게임 내 처리 |
|---|---|---:|---|
| step-180 | 180 스텝 | 80 | 기존 |
| step-360 | 360 스텝 | 140 | 기존 |
| ghost | 고스트라이드 | 60+ | 기존 |
| ghostride-kickflip | **고스트라이드 킥플립** | **140+** | **댄싱 트릭 신규 기술** |
| peter-pan | 피터팬 | 180 | 기존 |
| mango | 망고 | 200 | 기존 |
| wood | 찹더우드 | 120 | 기존 |
| pirouette | 피루엣(360도) | 210 | 기존 |

**고스트라이드 킥플립 설계:**

- `id: 'ghostride-kickflip'`
- `family: 'dance'`, `kind: 'technique'`으로 처리. UI에서는 **댄싱 트릭**으로 구분한다.
- 선행 기술: `ghost` **단독**, 숙련도 100% 마스터 필요. 일반 셀프훈련은 최초 해금 시 선행 조건을 적용한다.
- 기술 설명(사용자 제공): **고스트라이드 중 0.8초 넘게 달린 뒤 보드를 킥플립시켜 받아 타기.**
- 참고 점수 **140+**는 사용자가 전달한 Mini Longboard의 가변형 점수다. 게임 점수에 그대로 적용하지 않는다.
- 게임에서는 **난도 2, 기본점수 11, 실행시간 6초**를 적용한다.
- `고스트라이드 → 고스트라이드 킥플립` 경로. 테일트릭 `킥플립` 마스터는 요구하지 않는다.
- 기존 게임 캐릭터·보드 자산을 재사용하여 **보드 옆 주행 → 보드 뒤집기 → 착지** 동작을 표현한다. 기존 고스트라이드나 킥플립 애니메이션만 이름 바꿔 보여주지 않는다. 미리보기도 동일 기술을 표현해야 한다.
- [RidingBoards — Ghostride Kickflip](https://www.ridingboards.com/longboard-dancing/) 및 [Longboards USA — Ghostride Flip](https://longboardsusa.com/pages/the-10-easiest-longboard-tricks-to-become-an-expert)는 해당 기술을 롱보드 댄싱 연계 기술로 설명한다.
- `댄싱` 대회와 `프리스타일` 라인에서 사용 가능하도록 현재 `dance` 패밀리 규칙을 따른다.
- NPC 직접 전수라면 선행 기술 미충족이어도 즉시 습득하고, 습득 후에는 선행 미달성이어도 셀프훈련이 가능하다는 현재 예외 규칙을 그대로 따른다.

## 4. 해금 UI·자동 육성·이벤트 예외 처리

- 기술 화면의 잠금 기술에는 부족한 **선행 기술 이름과 숙련도**를 명확히 표시한다. 예: `트래플립: 킥플립 100% · 빅스핀 100% 필요`.
- 미습득 기술의 대회용 성공률 표시는 '습득 직후 예상 성공률'로 명시하고 현재 라인에 삽입되지 않도록 한다.
- 자동 육성은 목표 **미습득** 기술의 선행 기술을 역추적해, 선행 기술의 숙련도 100% 달성 → 새 기술 학습 → 새 기술 숙련까지 순차 진행하도록 한다. **이미 습득한 기술은 선행 기술이 잠겨 있어도 숙련도 향상 목표로 선택 가능하다.** 특정 기술만 반복하거나 학습 대기 상태에서 멈추지 않도록 한다.
- **NPC 전용 기술 전수 예외:** NPC 이벤트 선택 결과로 기술을 직접 가르쳐 주는 경우(예: `juns-clip`, `noa-pop`) **선행 기술의 습득·마스터 조건을 무시하고 즉시 해당 기술을 습득(study 100%)**시킨다. 선행 기술은 자동 습득되지 않으며, 이후 다른 상위 기술을 배우려면 그 기술에 명시된 선행 숙련도 100% 조건을 정상적으로 충족해야 한다. 이미 습득한 기술이면 중복 습득·중복 보상 없이 해당 이벤트의 다른 효과만 적용한다. 기술 레슨 및 일반 주간 연마에서 **미습득 기술을 새로 배우는 경우**에는 기존 선행 조건을 적용한다. 단, **이미 학습도 100%로 습득한 기술은 선행 조건과 무관하게 일반 주간 셀프훈련·레슨으로 숙련도를 추가 연마할 수 있다**. NPC 이벤트에서 기술을 가르친다고 명시된 선택지에만 이 예외를 적용한다.
- 기존 NPC의 경기 기술 생성은 NPC가 매주 훈련하지 않는 구조이므로, 새 선수용 숙련도 해금 규칙을 무작정 적용하지 말고 별도 난이도·성장 규칙으로 처리한다.
- 피투피 미리보기는 피글렛으로 보드에 다시 올라탄 뒤 피루엣을 잇는다. 알리 미리보기는 테일 팝, 도약, 수평 착지를 표현한다.
- 기술 트리의 순환 의존, 존재하지 않는 ID, 선행 조건 중복, 도달 불가능한 상위 기술을 자동 테스트한다.
- 스킬트리 원천 데이터는 코드 내 한곳에 정의하고 이 문서와 일치시킨다. 문서 수정만으로 게임 규칙이 자동 적용되는 것은 아니다.

## 5. 밸런스 검증 기준

1. 1년차에 기초 기술 연마와 첫 상위 기술 해금을 체험할 수 있는지 확인.
2. 3~4년차에 중급 기술의 진입률이 지나치게 낮지 않은지 확인.
3. 7~8년차에 고급·최고급 기술 도달과 선수별 전략 차이가 나타나는지 확인.
4. 416주 자동 육성 시 선행 기술만 무한 반복하지 않는지 확인.
5. 특수훈련 2배 학습·숙련도, 레슨 1.25배, 스팟 보너스와 누적되더라도 상한을 지키는지 확인.
6. 다른 종목과의 형평성, 고난도 기술 점수 및 성공률을 비교.
7. 기술 해금 규칙과 대회 채점 규칙 적용에 따른 경기 증빙·랭킹 버전을 정리.

v1.6 공식 경기 증빙은 규칙 버전 6을 사용한다. 예전 경기는 기록 당시 난도와 위험도로 재검증한다. 참가 방식 2개와 육성 전략 4개에 같은 12개 시드를 적용한 테스트에서 96회 모두 8년차를 완주했고 경기 점수는 0~100점 범위였다.
