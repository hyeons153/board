# LONGBOARD LIFE — 기술 트리 기획서

- 버전: v1.2 (2026-11-20)
- 상태: **구현 전 기획안**. 이 문서를 커밋해도 게임의 실제 기술 해금 규칙은 바뀌지 않음.
- 기준: `src/game/data.ts`의 기존 기술 29개(댄싱 16, 트릭 13), 사용자 제공 Mini Longboard 기술 분류·참고 점수와 선행 연계
- 목적: 기술 ID·선행 조건·숙련도 임계값을 명시해 향후 게임 밸런스와 UI를 일관되게 유지

## 1. 핵심 규칙

1. **기술 습득**: 학습도(`study`) 100%일 때 경기 라인에 사용할 수 있다.
2. **기술 마스터**: 이미 습득한 기술의 숙련도(`mastery`) 100%.
3. **상위 기술 해금**: 표에 기록된 **모든 선행 기술의 숙련도 100%**를 충족해야 새 기술의 학습을 시작할 수 있다. 두 기술이 적힌 경우 AND 조건이다.
4. **시작 기술**: 새 커리어의 기본 습득 기술은 시작부터 이용 가능하다. 변경 전 저장 기록에서 이미 습득한 기술은 잠그거나 삭제하지 않는다.
5. **기술 수 유지**: 기존 기술 29개(댄싱 16개, 트릭 13개)만 사용한다. 새로운 기술을 추가하지 않는다.
6. **기존 기술 이름 보정**: 기존 `pirouette`의 화면 명칭만 '피루엣 360'으로 변경한다. ID와 기록은 유지한다.
7. **시작 스킬 개편 제안**: `피봇 → 샤빗`의 해금 의미를 살리기 위해 기존 시작 기술 6개에서 `샤빗`을 제외한다. 새 시작 기술은 총 5개이며 대체 기술을 추가하지 않는다.
8. 선행 기술을 아직 마스터하지 못했다면 게임 UI에서 필요한 기술과 남은 숙련도를 보여 준다. 이미 연마 중인 기술, 이벤트 및 레슨도 동일 규칙을 따른다.
9. 기술을 처음 습득했을 때의 초기 숙련도·고난도 연마 속도·후반부 성장 둔화는 별도 시뮬레이션으로 조정한다. 만약 8년 내 상위 기술 도달률이 지나치게 낮다면 요구 조건 완화를 사용자가 결정할 수 있게 근거를 보고한다.
10. 연습과 대회에서의 기술 성공률은 별개다. 기본 연습 성공률은 체력 중심, 경기 기술 성공률은 숙련도·밸런스·난이도·위험도 및 장비 중심으로 유지한다.

| 기술 ID | 표시명 | 난도(현재) | 선행 기술 — 전부 숙련도 100% | 상태 |

| peter-pan | 피터팬 | 1 | 없음 | 시작 습득 |

| cross | 크로스스텝 | 1 | 없음 | 시작 습득 |

| sidewinder | 사이드와인더 | 2 | peter-pan | 기존 |
| v-spin | 브이스핀 | 3 | sidewinder + step-360 | 기존·복수 조건 |
| ghost | 고스트라이드 | 1 | 없음 | 독립 기초 |

| mango | 망고 | 1 | 없음 | 독립 기초 |

대표 라인:

- `180 → 360 → 피루엣 360 → 피루엣 540 → 피루엣 720`

- `망고` + `찹더우드` 모두 마스터 → `시계추 망고` → `시계추`
- `크로스스텝 → 백워드 크로스스텝`

## 3. 트릭 기술 트리 — 노즈 / 테일 (기존 13개 유지)

### 기준 및 점수 주의

- 분류와 **참고 점수**는 사용자가 제공한 [Mini Longboard](https://minilongboard.vercel.app/) 기술 설명에 따른다. 링크의 실시간 내용을 직접 검증한 것은 아니며 사용자가 전달한 원문을 기준으로 한다.
- **참고 점수 200·250·350·450·520 등은 Mini Longboard의 점수**이며, LONGBOARD LIFE 내부 경기 점수(`points`, 현재 6~15)와 **별개의 값**이다. 참고 점수를 그대로 대회 채점에 적용하지 않는다.
- 카테고리는 기술의 고유 **게임 UI 계열**이고, 선행 기술은 카테고리를 넘나들 수 있다. 노컴 빅스핀은 사용자가 제공한 기술 안내에서 **노즈**로 분류했으므로 그렇게 표시한다.
- 점수는 동일 계열의 단계와 난이도를 설계하는 **참고값**이다. 점수가 같더라도 앞선 기술의 동작과 숙련이 필요하면 더 높은 단계에서 해금할 수 있다.

### 3-1. 노즈트릭 · 회전 계열 (5개)

| 기술 ID | 표시명 | 참고 점수 | 현재 내부 기본점수 | 해금 선행 조건: 모두 숙련도 100% |
|---|---|---:|---:|---|
| pivot | 180 피봇 | 200 | 6 | 없음 · 시작 습득 |
| shuvit | 샤빗(셔빗) | 250 | 7 | 피봇 |
| no-com-big | 노컴 빅스핀 | 300 | 11 | 샤빗 + 노컴플라이(테일 공통 선행) |
| bigspin | 빅스핀 | 380 | 11 | 노컴 빅스핀 |
| bigger | 비거스핀 | 520 | 14 | 빅스핀 |

**주 경로:** 피봇 → 샤빗 → 노컴 빅스핀 → 빅스핀 → 비거스핀

기존 `pivot` ID는 유지하되 표시명을 '180 피봇'으로 정리하는 안이다. `no-com-big` 기술은 테일 팝 동작을 포함하더라도 참고 게임의 분류에 맞춰 노즈트릭 탭에 배치한다.

### 3-2. 테일트릭 · 팝·플립 계열 (8개)

| 기술 ID | 표시명 | 참고 점수 | 현재 내부 기본점수 | 해금 선행 조건: 모두 숙련도 100% |
|---|---|---:|---:|---|
| no-comply | 노컴플라이 | 220 | 7 | 없음 · 시작 습득 |
| front-pop | 프론팝(프론트 팝) | 250 | 10 | 노컴플라이 |
| pop-shuvit | 팝샤빗 | 250 | 10 | 샤빗(노즈 공통 선행) |
| kickflip | 킥플립 | 350 | 11 | 샤빗 |
| heelflip | 힐플립 | 350 | 11 | 팝샤빗 |
| varial | 베리얼 킥플립 | 450 | 14 | 킥플립 + 팝샤빗 |
| hardflip | 하드플립 | 450 | 15 | 힐플립 + 프론팝 |
| treflip | 트래플립 | **미제공** | 15 | 킥플립 + 빅스핀(노즈 공통 선행) |

**주 경로**:
- 노컴플라이 → 프론팝 → 하드플립 (힐플립도 마스터)
- 샤빗 → 팝샤빗 → 힐플립 → 하드플립 (프론팝도 마스터)
- 샤빗 → 킥플립 → 베리얼 킥플립 (팝샤빗도 마스터)
- 샤빗 → 킥플립 → 트래플립 (빅스핀도 마스터)

**분기 보완 제안**: 베리얼 킥플립은 동작 조합에 맞춰 기존 '킥플립 + 샤빗' 대신 '킥플립 + 팝샤빗'을, 하드플립은 '킥플립 + 프론팝' 대신 '힐플립 + 프론팝'을 요구한다. 이는 사용자 제공 기술 설명(180° 스핀 + 특정 방향 플립)을 반영한 신규 기획이며 실제 코드에는 아직 적용되지 않았다.

### 3-3. 기존 기술 유지 범위

- 신규 알리·노컴 비거스핀은 추가하지 않는다.
- 참고 자료에 있는 **고스트라이드 킥플립**, **돌 넘기**는 현재 기술 13개에 없으므로 이번 트리에 추가하지 않는다.
- 트래플립은 기존 게임 기술이지만 사용자 제공 참고 점수가 없어 **미제공**으로 기록한다. 임의의 참고 점수를 만들지 않는다.
- 13개 기존 트릭의 ID를 모두 유지하고, 내부 기본점수를 재설정할 때는 별도 대회 밸런스 시뮬레이션을 거친다.
- 시작 기술: 피봇·노컴플라이(트릭 2개), 댄싱 피터팬·크로스스텝·180(3개), 합계 5개. 샤빗은 피봇 마스터 후 학습 가능하도록 처음 습득 목록에서 제외한다.

### 3-4. 댄싱 참고 기술 점수 (확인되는 기존 기술만)

사용자 제공 기술 설명에서 현재 게임 기술에 직접 대응되는 항목만 표시한다. 이 값도 Mini Longboard 점수이며 게임 내부 점수로 변경하지 않는다.

| 게임 기술 ID | 표시명 | 참고 점수 |
|---|---|---:|
| step-180 | 180 스텝 | 80 |
| step-360 | 360 스텝 | 140 |
| ghost | 고스트라이드 | 60 이상(시간에 따라 변동) |
| peter-pan | 피터팬 | 180 |
| mango | 망고 | 200 |
| wood | 찹더우드 | 120 |
| pirouette | 피루엣 360 | 210 |

참고 자료의 '노즈 워크'(70점), '바디 배리얼'(200점)은 기존 게임의 독립 기술 ID로 확정되지 않았으므로 **새 기술로 추가하지 않는다**. 기존 '크로스스텝'은 노즈 워크와 동일 기술이라고 단정하지 않는다.

## 4. 해금 UI·자동 육성·이벤트 예외 처리

- 기술 화면의 잠금 기술에는 부족한 **선행 기술 이름과 숙련도**를 명확히 표시한다. 예: `트래플립: 킥플립 100% · 빅스핀 100% 필요`.
- 미습득 기술의 대회용 성공률 표시는 '습득 직후 예상 성공률'로 명시하고 현재 라인에 삽입되지 않도록 한다.
- 자동 육성은 목표 미습득 기술의 선행 기술을 역추적해, 선행 기술의 숙련도 100% 달성 → 새 기술 학습 → 새 기술 숙련까지 순차 진행하도록 한다. 특정 기술만 반복하거나 학습 대기 상태에서 멈추지 않도록 한다.
- 기존 NPC 이벤트에서 직접 기술을 지급하는 경우(예: `juns-clip`, `noa-pop`)는 선행 조건이 충족되지 않았다면 보상 증발 없이 대체 학습/연습 힌트 또는 후속 수업 이벤트를 제공한다.
- 기존 NPC의 경기 기술 생성은 NPC가 매주 훈련하지 않는 구조이므로, 새 선수용 숙련도 해금 규칙을 무작정 적용하지 말고 별도 난이도·성장 규칙으로 처리한다.
- 기술 동작 연출은 기존 29개 기술을 재사용한다. 새 기술 ID 추가 없이 기존 기술 ID를 유지한다.
- 기술 트리의 순환 의존, 존재하지 않는 ID, 선행 조건 중복, 도달 불가능한 상위 기술을 자동 테스트한다.
- 스킬트리 원천 데이터는 코드 내 한곳에 정의하고 이 문서와 일치시킨다. 문서 수정만으로 게임 규칙이 자동 적용되는 것은 아니다.

## 5. 밸런스 검증 기준

1. 1년차에 기초 기술 연마와 첫 상위 기술 해금을 체험할 수 있는지 확인.
2. 3~4년차에 중급 기술의 진입률이 지나치게 낮지 않은지 확인.
3. 7~8년차에 고급·최고급 기술 도달과 선수별 전략 차이가 나타나는지 확인.
4. 416주 자동 육성 시 선행 기술만 무한 반복하지 않는지 확인.
5. 특수훈련 2배 학습·숙련도, 레슨 1.25배, 스팟 보너스와 누적되더라도 상한을 지키는지 확인.
6. 다른 종목과의 형평성, 고난도 기술 점수 및 성공률을 비교.
7. 기술 해금 규칙과 대회 채점 규칙 적용에 따른 경기 증빙·랭킹 버전을 정리.
