# 롱보더 키우기 (Longboarder Tycoon)

퇴근 후 강변에서 시작하는 롱보드 커리어 시뮬레이션. React·TypeScript·Vite로 메뉴와 편집 화면을, Phaser 4로 도트 스팟·라이더·경기 재생을 구현했습니다. 훈련과 경기는 렌더링과 분리되어 서버에서 계산됩니다.

## 로컬 실행

Node.js 20.19 이상, 22.12 이상 또는 24를 사용합니다.

```sh
npm ci
npm run dev
```

콘솔에 표시되는 주소(기본 `http://127.0.0.1:5173/`)를 엽니다. 개인 커리어는 브라우저의 IndexedDB에 보관하며, 같은 브라우저와 주소에서 이어 할 수 있습니다. 명예의 전당은 별도 연결이 없을 때 개발 서버의 `.longboard/hall/`에 저장합니다.

행동을 확인하면 **2초간 수행한 뒤 결과**를 보여줍니다. 직접·자동 육성에 동일하게 적용되며, 이전 배속 선택은 적용하지 않습니다. 로컬 개발용 `WEEK_MS`로 검증 시간을 조정할 수 있습니다.

- 직접 육성: 메인에서 훈련·휴식·치료을 고르면 기존 상단 체력·능력치 게이지에 예상 증감이 표시됩니다. 선택지 배치는 유지하며 별도 상세 페이지를 열지 않습니다. 성공률과 필요한 설정을 확인한 뒤 **확인**을 누릅니다. 선택하기 전에는 주차가 진행되지 않습니다. 행동 결과 확인 → 이벤트 선택 → 이벤트 결과 확인 → 대회 → 다음 주 행동 선택으로 이어집니다.
- 자동 육성: AUTO ON은 주간 행동·이벤트 선택·대회 출전·전체 라인 재생·시상식·결과 확인·다음 주까지 모두 자동으로 진행합니다. 선택 장면을 2초 보여주고 2초 수행 → 결과 2초 확인을 거칩니다. 주간 행동은 시작 시 확정하고, 도중 전략 변경은 다음 주부터 적용합니다. AUTO OFF로 직접 육성으로 돌아갈 수 있습니다.
- 대회: 해당 주차에 출전 종목을 선택할 수 있습니다. 출전 종목을 누른 순서대로 체력을 쓰며, 저장한 라인이 없으면 연계형 라인을 사용합니다. 선수 입장과 60초 라인 전체를 순서대로 재생하며, 스킵 버튼으로 결과를 볼 수 있습니다.
- 능력치 상한은 200이며 체력·기술 학습·숙련도는 100을 유지합니다. 1~2년차 뉴비부 → 3~4년차 일반부 → 5~6년차 오픈부 → 7~8년차 마스터부로 승급합니다. 0년차 표기는 사용하지 않습니다.
- 스팟은 메인 좌측 상단 지도에서 이동합니다. 각 스팟의 단골 라이더·훈련 성장 보너스·해금 조건을 볼 수 있고 이동으로 주차나 체력이 소모되지 않습니다. 자동 육성 설정은 상단 AUTO 버튼 왼쪽에 있습니다.
- 라이더는 연간 6개 대회에 출전할 수 있습니다. 일반 대회는 댄싱·트릭·프리스타일 중 1종목만 선택합니다. 홀수 해 연말은 롱페, 2·4·6·8년차 연말은 서울·도쿄·바르셀로나·로스앤젤레스 국제대회입니다. 국제대회는 체력·부상·자동 출전 설정과 관계없이 3종목 모두 참가합니다. 8년차 마지막 국제대회 결과와 보상을 확정한 뒤 은퇴합니다. 기존 대회 기록과 경기 검증 근거는 유지하며 향후 일정부터 새 규칙을 적용합니다.
- 대회 창에는 과거 대회의 종목별 순위·점수·포인트·명성·상금과 전체 순위를 바로 표시합니다. 전체 라인은 다시 보기에서 불러오며 스킵도 가능합니다.
- 게임 서버는 싱가포르(`sin1`)에 배치합니다. 서버는 커리어를 처리해 암호화된 저장본을 브라우저에 돌려줍니다. 일반 응답은 경기 요약을 담고, 미확인 대회와 다시 보기 요청에는 전체 재생 기록을 포함합니다. 변경이 없는 상태 확인은 204로 응답합니다.

## 인게임 화면

게임은 화면 높이를 사용하는 단일 프레임입니다. 메인에서 주간 행동과 능력치 게이지를 확인하고 하단 메뉴로 기술·대회·상점·전체 메뉴를 열어 라인·선수·계정·명예의 전당까지 이용합니다. 긴 일지는 상단 버튼의 보조 창으로 분리했습니다. 공통 댄싱·트릭 설명은 사용자가 지정한 [보드를 타보자!](https://minilongboard.vercel.app/) 도감을 참고해 보완했으며, 이 게임의 성장·점수 규칙은 별도로 유지합니다.

32개 기술은 몸·데크의 회전과 양발 접촉을 각각 계산하는 2D 도트 애니메이션을 사용합니다. 훈련 목표와 저장한 라인, 기술 도감 미리보기, 선수·라이벌 경기, 은퇴 하이라이트에 같은 동작을 적용합니다. `npm run review:animation`으로 기술별 자세와 경기 장면을 `.longboard/animation-review/`에 렌더링할 수 있습니다. 화면 용어는 ‘라인’으로 통일했으며 이전 일지에 남아 있는 옛 표현도 표시할 때 변환합니다.

캐릭터는 둥근 머리·볼·손발과 아담한 몸 비율을 공유합니다. 선수 등록과 상점 외형 변경에서 성별, 4종 헤어스타일, 피부 6색, 머리·상의·하의·신발·데크 각 8색을 선택합니다. 검정·흰색 데크를 지원하며 성별은 능력치에 영향을 주지 않습니다. `npx tsx scripts/render-appearance.ts`로 새 외형과 킥플립 비교 이미지를 렌더링할 수 있습니다. 메인 행동 9개는 고정된 2줄(좁은 화면 3줄) 안에서 스크롤 없이 배치되며, 스팟 지도 버튼은 우측 상단에 있습니다.

훈련은 체력이 낮을수록 성공률이 내려갑니다. 실패하면 체력은 소모되지만 능력치와 기술 진척은 오르지 않습니다. 미리보기의 상승 범위는 성공했을 때의 값이며, 부상 위험도 있습니다. 대회는 체력 0에서도 출전할 수 있고, 대회 기술 성공률·연계·점수·자동 라인 생성에는 현재 체력이 영향을 주지 않습니다. 출전 후 체력은 소모됩니다. 기존 경기 기록은 저장 당시의 수행 규칙으로 재검증합니다.

장비·스폰서와 자동 육성 설정은 이벤트나 결과 확인 중에도 열 수 있습니다. 메뉴를 보는 동안 진행 중인 훈련은 마무리되며, 결과는 게임 화면으로 돌아온 뒤 확인합니다. 진행 중 장비를 교체해도 해당 훈련은 시작 시점의 장비·라인으로 계산하고 다음 훈련부터 변경을 적용합니다. 이벤트는 선택 후 실제 변화와 획득 내용을 보여 주며, 직접 육성은 확인 버튼, 자동 육성은 2초 결과 표시 후 이어집니다.

장비는 데크 8종·트럭 7종·휠 7종과 액세서리 30종으로 구성합니다. 기본 능력치와 장비 보정을 분리하며 액세서리는 최대 3개를 장착합니다. 상점에서 보유 상태·희귀도 필터, 교체 비교, 착용 미리보기를 제공합니다. 기존 베어링과 과거 경기 입력은 보존합니다. 저장 형식 전환과 운영 승인 범위는 [장비 개편 적용 검토](docs/equipment-upgrade.md)에 정리했습니다. `npm run review:equipment`는 장비 그래픽을, `npm run verify:equipment`는 별도 로컬 미리보기에서 구매부터 자동 대회까지 검증합니다.


## Neon board2 및 Vercel 설정

1. 기존 Neon 프로젝트 **board2**의 명예의 전당용 연결을 Vercel의 서버 전용 `HALL_DATABASE_URL`로 설정합니다. 연결 문자열은 배포나 브라우저 코드에 공개하지 않습니다.
2. `HALL_DATABASE_DIRECT_URL`에 board2의 direct 연결을 설정해 `npm run db:migrate`를 실행합니다. 대상 프로젝트와 브랜치를 확인한 후 적용합니다. 이 명령은 기존 마이그레이션을 재사용하며 비공개 게임 기록을 board2로 복사하지 않습니다.
3. `GAME_SAVE_SECRET`과 `AUTH_RATE_SECRET`에는 각각 32자 이상의 무작위 비밀값을 사용합니다. 기존 배포는 `GAME_SAVE_SECRET`이 비어 있으면 설정된 `AUTH_RATE_SECRET`으로 저장 키를 파생합니다. 실제로 사용된 키를 유지해야 기존 브라우저 저장본을 다시 열 수 있습니다.
4. 운영 배포에서 새 라이더를 등록하고 새로고침 후 이어 하기가 되는지 확인합니다. 명예의 전당에서는 공개 선수 목록과 글로벌 랭킹을 확인합니다.

`/api/game`은 Vercel의 Node.js 함수입니다. board2에는 명예의 전당 계정·세션, 공개 프로필, 공식 순위, 신고 정보만 저장합니다. 일반 육성, 장비 관리, 경기 재생, 개인 은퇴 기록은 브라우저 저장본으로 처리합니다.

기존 board 데이터는 보존합니다. 이전 DB가 읽기 가능해지면 운영 서버에 `LEGACY_SAVE_DATABASE_URL`을 한시적으로 지정할 수 있습니다. 이전 세션이 남아 있고 새 브라우저 저장본이 없는 경우 계정 화면에서 기존 기록을 요청해 가져옵니다. 기존 공개 계정과 랭킹을 새 명예의 전당에 유지하려면 별도로 이관해야 합니다.

## 검증과 구조

```sh
npm test
npm run build
```

- `src/game/`: 기술·스팟·이벤트·밸런스 설정, 시드를 사용하는 훈련과 경기 엔진. NPC에도 선수와 같은 경기 엔진을 적용합니다.
- `src/scene/`: 절차적으로 생성한 원본 도트 배경과 스프라이트. 경기 결과 로그가 재생을 구동합니다.
- `server/`, `api/`: 서버의 게임 처리, 암호화된 브라우저 저장본, 명예의 전당 API와 PostgreSQL 저장소. 명예의 전당 공개는 서버가 발급한 은퇴 기록으로 검증합니다.
- 주간 진행은 브라우저 페이지의 주기적 요청으로 처리합니다. 이미 등록된 페이지는 백그라운드에서 지연된 시간을 다음 요청에 반영합니다. 페이지를 새로 열면 이전 페이지가 닫혀 있던 시간을 추가하지 않습니다. 갑작스러운 종료로 마지막 요청이 전송되지 않은 경우 마지막으로 서버가 확인한 진척까지만 보존됩니다.

## 2차 콘텐츠

- 야간 광장과 대회 연습장의 해금 조건은 육성 홈에 표시됩니다. 대회 연습장은 연계 훈련에 성장 보너스를 줍니다. 라인 리허설은 신규 훈련과 자동 선택에서 제외하며 예전 기록은 보관합니다.
- 기술 도감에서 32개 기술의 선행 조건과 대회 성공률, 도트 미리보기를 볼 수 있습니다. 자동 육성은 행동·이벤트·대회·결과 확인을 이어서 진행합니다.
- 장비·스폰서에서 데크·트럭·휠 22종과 액세서리 30종을 구매하고 장착하거나 판매할 수 있습니다. 액세서리는 최대 3개이며 기존 베어링은 보유 기록을 유지한 채 액세서리로 전환됩니다. 계약은 시즌당 한 곳이며, 해당 시즌 대회에서 협찬 종목으로 입상하면 다음 시즌 계약이 갱신됩니다.
- 대회 결과에서 선수별로 전체 라인을 관람하거나 스킵으로 시상식을 볼 수 있습니다. 1차 경기 기록은 당시 저장한 플레이어 로그로 재생됩니다. 재생은 저장된 경기 로그를 사용하고 보상을 지급하는 시점은 경기 확정 시점입니다.
- 기존 PostgreSQL 테이블은 동일합니다. 커리어 JSONB에 새 필드를 추가했고, 1차 저장에 없는 필드는 기본값으로 읽습니다. 기존 선수와 기술, 점수, 입상 기록을 변환하는 SQL 단계가 필요하지 않습니다.

기술 설명은 롱보드 스텝 및 프리스타일 용어를 참고했습니다. [Simple Longboards](https://www.simplelongboards.com/classic-videos) · [롱보드 댄싱·프리스타일 용어 사전](https://cdn.hs-heilbronn.de/1ab3cb8526054e7a/2c85a03225b2/BuchmannSchramm_Dictionary_LDF_2025-01-29.pdf)

## 3차 커리어와 온라인 기능

대회 출전 선택 → 종목별 관람 → 점수 발표·시상식 → 육성 계속과 이벤트 대화·선택지, 부상 확인은 육성 홈의 도트 게임 화면 안에서 진행합니다. 대회 일정은 일정·기록 조회용이며 과거 경기도 게임 화면에서 다시 봅니다. 대회 결과 확인 중에는 서버가 주간 진행을 멈추고 새로고침 후에도 미확인 결과를 복구합니다. 직접 육성은 **육성 계속**을 누르면 다음 행동을 기다리며, 자동은 관람·시상식 뒤 확인까지 처리하고 다음 주를 시작합니다.

- 8년차 마지막 국제대회 결과와 보상을 확정한 뒤 은퇴 기록을 생성합니다. 레전드, 종목별 챔피언, 테크니션, 베테랑, 조기 은퇴 엔딩과 라이벌 에필로그를 지원합니다. 개인 명예의 전당에서 은퇴식을 다시 볼 수 있습니다.
- 명예의 전당 계정은 공개 기능에 사용합니다. 아이디와 비밀번호로 로그인하며 이메일은 수집하지 않습니다.
- 은퇴 선수는 기본 비공개입니다. 공개·철회, 다른 선수의 공개 프로필 조회, 이름 앞부분 검색, 부문·엔딩·완주 필터, 페이지네이션을 지원합니다. 계정 삭제는 명예의 전당 세션, 공개 프로필, 순위와 신고 데이터에 적용됩니다.
- 공식 순위는 서버에 남긴 경기 입력과 시드로 결과를 재현해 검증합니다. 8년 종합 점수에는 부문·메이저·시즌 챔피언 가중치를 적용합니다. 기존 검증 근거가 없는 경기는 개인·공개 프로필에 보존하고 공식 점수와 구분합니다.
- 같은 브라우저의 마지막 은퇴 선수가 새 회차의 선배로 등장합니다. 이전 스탯과 기술 숙련도는 상속하지 않습니다. 자동은 중요한 이벤트·대회·부상 확인도 선택하며 계속 진행합니다.
- `0001_military_leopardon.sql`은 기존 세 테이블에 계정·공개 프로필·랭킹·신고·인증 제한·로컬 이관 이력 테이블을 추가합니다. 기존 커리어 스냅샷을 보존합니다. PGlite 명예의 전당도 같은 마이그레이션을 적용합니다.

## 검증과 운영

캐릭터는 사용자가 제공한 설정화를 바탕으로 준비한 전신 스프라이트를 플레이어·NPC·프로필·시상식에서 함께 사용합니다. 얼굴과 몸통을 단순 도형으로 다시 그리던 렌더러는 제거했고, 원본 기반 그림의 목·옷깃·몸통·바지·신발 비율을 유지합니다. 헤어 13종, 상의 디자인 7종, 하의 4종, 신발 디자인 3종, 눈 색상 6종을 조합할 수 있습니다. 남녀 추천 코디 각 5종과 정면·양 측면·후면 미리보기를 제공합니다. 기존 색상 인덱스와 저장 기록을 유지하며 추가 외형 필드가 없는 기록은 기본 후디·카고·스니커즈로 표시합니다. 제작 이미지와 프롬프트, 적용 범위는 [캐릭터 아트 기록](art/characters/README.md)에 남겼습니다.

기술 동작은 지정한 미니게임의 공개 기술 설명·발 위치와 사용자가 제공한 동작표를 다시 대조했습니다. 피터팬·크로스스텝은 지지 발을 유지한 채 한 발씩 이동하며, 피봇은 노즈 축, 피루엣은 지지 발, 플립은 보드의 독립 회전을 사용합니다. 해당 사이트 설명에 따라 하드플립의 플립 방향을 힐플립 방향으로 맞췄습니다. 경기 채점·저장 규칙은 변경하지 않았습니다.

`npm run review:appearance`는 코디·방향별 모습·NPC·대표 동작을 `.longboard/animation-review/character-*.png`에 출력합니다. `npm run review:animation`은 32개 기술 전체의 동작 검토 이미지를 생성합니다.

`npm run simulate -- 12`는 전략마다 12개 시드로 8년 전체를 반복 검증하는 내부 도구입니다. 플레이 화면에 시간 단축 기능을 추가하지 않습니다.

`npm test`는 DB에 접근하지 않는 브라우저 커리어 API, 명예의 전당 공개와 철회, 기존 클라우드 기록 호환성을 확인합니다. `npm run build`는 브라우저 코드와 Node.js 서버의 모듈 해석을 검사합니다.

신고 검토와 비공개 처리는 [운영 절차](docs/operations.md)를 따릅니다. 공개 이름에는 최소한의 금칙어 검사와 사용자 신고를 적용합니다. 신규 표현의 판단에는 운영자 검토가 필요합니다. 실시간 멀티플레이, 3D, 생성형 NPC 대화, 결제와 커뮤니티 기능은 이번 범위에서 제외했습니다.

## 플레이·경제 조정 (2026-11-18)

- 기초 훈련은 속도→카빙, 카빙→밸런스, 연계→속도, 밸런스→카빙의 주/부 능력치 구조입니다. 댄싱 연마는 기술 학습·숙련과 속도·카빙, 트릭 연마는 기술 학습·숙련과 연계·밸런스를 올립니다. 공통 계산으로 예상치와 실제 결과를 맞춥니다. 선택지는 기초 4개/연마·휴식·치료 4개의 두 줄입니다.
- 자동 출전은 한 종목 또는 불참을 고릅니다. 기존 다중 설정은 첫 종목을 사용하고, 기존 다종목 경기 기록과 국제대회의 3종목 출전은 유지합니다.
- 대회 관람의 x2는 경기 시간·카운트다운·동작·시상식을 함께 두 배로 재생합니다. 중간 변경 시 시간이 되돌아가지 않으며 주간 훈련 시간과 실제 경기 점수에는 영향을 주지 않습니다. 선택한 속도는 이 브라우저에 보관합니다.
- 자동 설정은 내용 높이의 작은 창을 사용하고 전략별 차이를 표시합니다. 스팟 카드의 중복 능력치 설명을 제거하고 라인 편집 저장·비우기를 자동 생성 버튼 위에 배치합니다.
- 일반 대회 1위 상금은 8만원, 참가 보상은 4천원입니다. 메이저 상금은 1.5배, 국제대회 상금은 2배입니다. 시즌 1~3위 보상은 6/4/2.5만원입니다. 장비는 입문 2.8만원부터 최고 데크 320만원·트럭 220만원·휠 240만원까지 장기 목표가 되도록 조정합니다. 액세서리는 희귀도별로 조정합니다.
- 기존 보유금·장비·과거 상금은 바꾸지 않습니다. 새 구매의 지불액을 기록하고 판매가는 구매액의 55%를 사용합니다. 구매액이 없는 기존 장비는 이전 가격을 기준으로 판매해 가격 인상 차익을 막습니다. DB 스키마 변경 없이 기존 저장 형식의 선택 필드를 확장합니다.
